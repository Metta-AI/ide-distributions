# researcher

A research worker of the Softmax IDE. The Orchestrator's watcher starts one Session per Task in
this profile. The Session claims its Task (which creates its git worktree), works only there,
records what it learns as claims and Experiment runs, proposes follow-up Tasks and submissions
through its Task, waits through `task.wait` when something outside its control must happen, and
ends by completing the Task. It speaks only to the Orchestrator (`task.ask`), never to the user.

Everything it does lives in the shared package [`core/`](../core/README.md). This folder is the
Hermes distribution shell:

| File | What it is |
|---|---|
| `distribution.yaml` | The manifest: the variables `.env` must define (`env_requires`). |
| `config.yaml` | The shipped Hermes config: the default model (`recursive/flint-v1.0:free`, falling back to `moonshotai/kimi-k3`; the user changes it through the bridge), approvals off, no deny list, memory off, the `researcher` plugin and the `ide-researcher` toolset, the terminal environment passthrough. |
| `SOUL.md` | The system prompt, generated by `uv run python tools/build_prompts.py --write`; do not edit by hand. |
| `plugins/researcher/` | The plugin entry (`plugin.yaml` lists the tools; `__init__.py` imports `research_core` from the path in `local/core-path.txt`). |
| `scripts/prepare.py` | Preparation after install or update. |
| `.no-bundled-skills` | The profile's skills come from `core/src/research_core/skills/` through `skills.external_dirs`. |
| `local/` | Written at preparation; not shipped. |

## Tools

Fourteen tools: `task`, `claim`, `experiment`, `version`, `upload`, `settings`, `workspace`,
`xp`, `platform`, `forum_post`, `wiki_edit`, `softmax_api`, and read-only `goal` and
`directive`. A Researcher cannot create Goals, submit, notify the user, or reach GitHub and
attachments; it proposes Tasks and submissions through its own Task.

## Install

```bash
hermes profile install ~/ide-distributions/researcher --name researcher --yes
# write ~/.hermes/profiles/researcher/.env (see distribution.yaml env_requires); IDE_WORKSPACE
# must be the same path as the Orchestrator's
<hermes python> ~/.hermes/profiles/researcher/scripts/prepare.py \
  --source ~/ide-distributions/researcher --hermes $(command -v hermes)
```

Several Researcher Sessions run in this one profile. To run them in separate profiles instead,
install it again under other names (`researcher-1`, `researcher-2`) and set
`IDE_RESEARCHER_PROFILES` in the Orchestrator's `.env`; the Orchestrator's `prepare.py` and
every Coworld switch configure the sibling profiles too.
