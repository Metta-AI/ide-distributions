# Expert consultation

Apply D-13 when progress stalls and D-07 when assessing advice: a recommendation is not evidence.

Use expert advice for a concrete unresolved question: difficult policy design, ambiguous evidence,
or a repair that failed twice. Routine work does not require a consultation. Discover the current
advisory tool, supported models, costs and limits; its absence is not a reason to stop ordinary work.
Use the default model first; choose a more expensive expert for a difficult question or a specific
issue the earlier advice did not resolve, within the user's existing budget.

Ask the expert to act as a policy-research consultant. Supply one question, the relevant source,
verified game and host contracts, original evidence, constraints and failed approaches. Exclude
credentials. Request a concise diagnosis or recommendation, a focused patch when relevant, and
verification steps. Ask it to separate observed facts from hypotheses and name missing evidence.
For code, request plain source without display line numbers. Do not ask it to start another research
loop or consult another expert.

Read the answer as advice. Inspect proposed changes against the actual game and policy source,
then run the relevant checks through the existing tools. A consultation cannot establish that code
was compiled, uploaded, submitted or played. Continue the original task with the current agent;
retain the advice and subsequent evidence. Do not repeat the same consultation without new evidence.
